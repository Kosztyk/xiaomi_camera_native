## Xiaomi Camera Native v0.3.8 — HACS readiness

Packaging-only release focused on HACS discoverability and CI verification.

- HACS-compatible manifest metadata and friendly HACS display name
- GitHub Actions jobs for HACS, Hassfest and local packaging checks
- HACS installation guidance and repaired documentation links
- Packaging test suite and documented validation scope

**No changes to camera streaming, Xiaomi authentication, PTZ controls,
codecs or device discovery.** The GitHub release should be published only
after the CI jobs have successfully completed on the new source revision.
